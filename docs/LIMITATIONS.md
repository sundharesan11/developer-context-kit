# Limitations

Linux support is not claimed until its suite and acceptance run there. Windows is unsupported. Client-data migration is not implemented. There is no backup or sync; a lost laptop can expose local data if disk protection is inadequate and can lose the only copy.

This pilot supports multi-record onboarding, with one registry publication point and crash/replay tests. The checks do not prove behavior against a malicious same-user process, real agent routing, live accounts, legal redistributability, or production readiness. Fresh-agent smoke checks are deferred until approved real-home activation.

The skill builder has deterministic workspace, format and disposable-installation tools. Its conversational `SKILL.md` and live-model behavior evaluation are deferred. Validation does not run generated helpers or prove that a skill asks good questions. B's tests prove file, approval and recovery guards only; they do not prove discovery, routing, fresh-session behavior or real-home readiness. The validator intentionally accepts a strict frontmatter subset described in [SKILL-BUILDER.md](SKILL-BUILDER.md). Export and publication remain unavailable.

Third-party acquisition stages an explicit bounded file selection only. It does not infer package roots, dependency trees, generated bundles, optional extensions, licenses to redistribute, native-host support or installation recipes. A selected SKILL.md may depend on omitted files. Large/data-heavy skills and repositories can exceed the fixed 24-file, 128-KiB/file, 1-MiB-total, 10,000-entry and 2-MiB/tree-response caps; LIMIT is expected and there is no archive/clone/auth fallback. Taste cannot be acquired under this release-only policy while no stable release observation exists.

Selection accepts conservative ASCII paths and rejects secret-like names, including some legitimate `id_mapping` and database filenames. Unselected names may contain spaces or Unicode; a Unicode-fold alias of a selected ASCII name is not detected, but is never written. These path rules do not prove the selected contents are free of secrets or malicious instructions. Acquisition never proves tag-to-commit binding or upstream-history membership, and source licenses/notices must be explicitly selected.

Default Claude, Codex, shared Agents, Gemini, Cursor and Command Code homes are protected by the pilot fence. Existing Claude/Codex environment overrides are recognized; other custom host discovery locations are not discovered automatically and must be declared in `pilot.forbidden`. Native providers, actual host discovery, live-home activation, adapters/updaters and schedules remain separate work. An incomplete stage is preserved without automatic recovery; see [STORAGE.md](STORAGE.md).
